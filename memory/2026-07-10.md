## Skill Updates

- Improved repo debugging memory: web_h5 mining inventory must use the same WS-authoritative source at refresh, pre-execution, and executor-time gates. A partial migration leaves OCR able to veto valid item plans.
- Added planner diagnosis pattern: replay exact RL `board_before` snapshots at multiple search depths and compare the first action plus the planner's own weighted objective. Rolling replanning cannot repair a horizon error when the first action changes.
- Added executor diagnosis pattern: compare `verify_success` with `board_after`; a false verification on an already changed board can interrupt multi-step plans and inflate internal shovel accounting.
- Improved planner repair pattern: keep the normal shallow horizon, then conditionally compare a deeper plan only when the shallow winner spends a scarce item. This fixes item-driven horizon errors without changing latency and behavior for every shovel-only board.
- Improved config routing pattern: when a repo supports both legacy flat and newer nested settings, normalize at the phase boundary and make the nested value explicitly win; otherwise an enabled feature can remain silently disconnected.
