# 飛寵 UI 原型 · 三個方向

同一份需求（6 個痛點）做出三種取向的飛寵管理介面原型，全部是**單一離線 HTML**，直接用瀏覽器開啟就能操作，無任何外部資源（無 CDN、無 fetch）。

先開 [`index.html`](index.html)：它是比較落地頁，列出三個版本各自最適合誰、最強解掉哪個痛點，並用對照表逐項比較。卡片裡的連結都是相對路徑，點了就能跳到對應原型。

## 三個方向

| 版本 | 檔案 | 一句話 | 最適合 |
|------|------|--------|--------|
| **A · 密集戰情表** | [`version-a-ops-table.html`](version-a-ops-table.html) | 資訊密度最高、批次操作最順的「戰情表」 | 我有 300 隻、要快速管理與分解的進階使用者 |
| **B · 圖鑑卡片牆** | [`version-b-gallery.html`](version-b-gallery.html) | 以圖標為主角的卡片牆，靠外觀辨識 | 想用看的、靠外觀辨識的使用者 |
| **C · 種類瀏覽器** | [`version-c-species-browser.html`](version-c-species-browser.html) | 左側種類索引下鑽，類別導向最直覺 | 我要抓指定類別 |

### A · 密集戰情表
表格式高密度版面，最強的是**痛點3（即時一鍵過濾、單一搜尋框同比對種類名＋詞條名）**與**痛點1（可搜尋的種類多選下拉、鎖定單一種類）**。桌面用視窗化只渲染可視列；sticky 批次列可全選（略過鎖定）＋批次分解。

### B · 圖鑑卡片牆
讓**痛點2（圖標）**發光：圖標是卡片主角（64–72px，含品質色環與星級）。種類藥丸單點即精準隔離，平鋪 ↔ 依種類一鍵切換。

### C · 種類瀏覽器
直接打中**痛點1（抓指定類別）**：左側「種類索引」一點即鎖定單一種類，可即時搜尋收斂清單。三版中唯一在規模（300+ 隻）與手機自適應都達標的版本。

## 六個痛點

1. 抓指定飛寵類別（可搜尋的單一種類精準篩選）
2. 看到圖標（每隻可見頭像，設計主體）
3. 過濾更精細但更簡單（即時／一鍵／單一搜尋框同比對種類名＋詞條名）
4. 300+ 隻流暢顯示與管理（視窗化／顯示總數＋篩選數／批次選取＋分解／sticky 批次列）
5. 種類視圖開關（依種類分組 ↔ 平鋪全部 一鍵切換）
6. 手機自適應（不橫向捲動／觸控 ≥40px／篩選收抽屜／版面重排）

逐項通過情形（✓ 達標／◐ 部分／○ 未達標）見 `index.html` 的對照表與註解。

## 如何開啟

**電腦**
- 直接雙擊任一 `.html`，或在瀏覽器用 `Ctrl/Cmd + O` 開啟。
- 想從比較頁進入，先開 `index.html` 再點卡片按鈕（連結為相對路徑，三個原型需與 `index.html` 放在同一資料夾）。

**手機**
- 把同一個 `.html` 檔傳到手機（雲端硬碟、傳檔、或瀏覽器開啟），直接開即可，因為完全離線、無外部依賴。
- 或用區網：在電腦這個資料夾起一個簡單伺服器，手機連同一 Wi‑Fi 開電腦 IP。
  ```bash
  # 在 mockups/fly_pet/ 目錄下
  python -m http.server 8000
  # 手機瀏覽器開 http://<電腦區網IP>:8000/index.html
  ```

## 備註

- 目前資料是內建的 mock（312 隻 / 40 種），圖標是依 config_id 算出的彩色漸層頭像；之後接真實 sprite 只需替換圖標內層 `<img>`。
- 三個檔案都通過離線自足檢查（無外部 `src`/`href`/`link`/`import`/`fetch`）。
