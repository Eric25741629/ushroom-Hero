# 🍄 菇勇者自動化掛機 - 技術架構文檔

本文件旨在總結專案重構後的模組化結構、核心演算法邏輯以及運作機制，以便開發者與 AI 快速理解系統現狀。

---

## 1. 目錄結構 (Module Segregation)

專案採用嚴格的模組化設計，將功能依性質拆分：

### 📂 `miner/` (挖礦核心模組)
*   **`mining_service.py`**: 挖礦高層協調器。負責截圖、呼叫分類器、啟動 Planner、呼叫 Executor 執行動作，並包含**死循環偵測**。
*   **`core/`**: 基礎定義。
    *   `config.py`: 全域路徑、OCR 地址、方塊成本、盤面座標。
    *   `mechanics.py`: 道具（炸彈、鑽頭）的作用範圍計算邏輯（唯一真理來源）。
    *   `ocr_utils.py`: 道具數量與鎬子數量的 OCR 辨識，含**二值化預處理**。
*   **`planning/`**: 決策核心。
    *   `smart_planner.py`: **A* 搜尋演算法**。負責多步規劃與成本計算。
    *   `executor.py`: 將規劃指令（type, pos）轉化為實際的 ADB 點擊動作。
*   **`models/`**: 視覺辨識。
    *   `classifier.py`: CNN 盤面分類器，將截圖轉為方塊標籤。
    *   `checkpoints/`: 存放訓練好的模型檔 (`best.pth`)。
*   **`rl/`**: 強化學習與紀錄。
    *   `rl_recorder.py`: 事件記錄器，保存每一輪的盤面與決策 (`events.jsonl`)。
*   **`scripts/`**: 工具與測試。
    *   `serve_ai.py`: WebSocket 伺服器，供網頁前端連線測試。
    *   `debug_with_image.py`: 載入單張截圖測試辨識與規劃效果。

### 📂 `utils/` (共用工具)
*   **`logging_utils.py`**: 統一日誌系統。支援設備分檔、自動滾動 (Rotation) 與 **[檔案:行號]** 標註。
*   **`wake_up_handler.py`**: 獨立出的設備喚醒、解鎖與連線同步邏輯。

## 2. 挖礦 AI：A* SmartPlanner 邏輯

演算法目標：**以最小代價達成全收集，並安全下樓。**

### 優先級排序 (Priority)
1.  **礦物剩餘量 (Remaining Pits)**：優先選擇能讓畫面上礦物變少的路徑。
2.  **下樓狀態 (Floor 7 Open)**：在礦物量相同時，優先選擇能打通第 7 層的狀態。
3.  **累積成本 (Accumulated Cost)**：在上述條件一致時，選擇總花費最少的路徑。

### 關鍵機制：
*   **暴露檢查 (Exposure)**：只有連通到地表或已連通空氣的方塊才是 `Reachable` (可挖掘)。AI 會模擬挖掘後的連鎖連通反應。
*   **捲動保護 (Scrolling Protection)**：如果一個動作會導致第 7 層打通（觸發捲動），AI 會檢查 **Row 0 與 Row 1** 是否還有礦。若有，則禁止該動作 (Prune)，直到上方清空為止。
*   **道具門檻**：
    *   鎬子成本 = 1.0 / 道具成本 = **2.99**。
    *   **決策原則**：當一個道具能節省 **>= 3 個鎬子** 時，AI 會自動優先選擇道具。

## 3. 日誌與除錯 (Maintenance)

### 日誌系統
*   **主日誌**: `logs/{IP}.log` (主流程、遊戲狀態切換)。
*   **挖礦日誌**: `logs/miner_{IP}.log` (盤面符號、AI 決策細節)。
*   **格式**: `時間 - 層級 - [檔案:行號] 訊息`。

### 異常處理
*   **死循環偵測**: 若連續 3 輪盤面與動作完全一致，系統會自動截圖存至 `logs/stuck_debug/` 並中止流程。
*   **OCR 備援**: 若連續多次讀到道具為 0，會啟動冷卻機制暫停道具使用，直到重啟。

## 4. 遊戲規則備忘 (The Rules)
*   **炸彈**: 3x3 區域 + 十字延伸 (距離2格)。
*   **鑽頭**: 直通底部 + 底部左右各一格。
*   **岩石**: 需要 2 下鎬子 (HP 2)。
*   **寶箱**: 必須完全清除所有部分才能得分（AI 會自動追蹤標籤中不含 `dug` 的 `pit`）。
