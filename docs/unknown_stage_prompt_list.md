## 建議給本地大模型的提示詞

### 通用判斷提示詞

```text
你是遊戲自動化的畫面判讀器。

請根據「截圖」和「OCR 文字」判斷目前畫面屬於哪一個 stage。

可用 stage：
- 主頁面
- 農場/作物頁
- 家族頁
- 商店頁
- 活動/副本頁
- 戰鬥/關卡頁
- 公告/彈窗
- 離線獎勵
- 車位倉庫
- 異地登錄
- 未知

判斷原則：
- 以截圖為主，OCR 為輔。
- 若畫面不是主頁，但有明確子頁特徵，請不要硬判成主頁。
- 若資訊不足，輸出 `未知`，不要猜。
- 若畫面有多層疊加，請優先判斷最上層可操作畫面。

輸出格式請固定為 JSON：
{
  "stage": "...",
  "confidence": 0.0,
  "evidence": ["..."],
  "notes": "..."
}
```

### 農場頁專用提示詞

```text
請判斷這張遊戲截圖是不是農場 / 作物頁。

農場頁常見特徵：
- 底部有「日誌 / 好友 / 偷菜 / 商店 / 返回」
- 畫面中央是多格作物地塊
- 會有「生長中 / 澆水中 / 種植中 / 駐守中」
- 上方有資源列、箱子、角色、作物 NPC

如果符合以上大部分特徵，請輸出：
{
  "stage": "農場/作物頁",
  "confidence": 0.0,
  "evidence": [...],
  "notes": "..."
}

若不是，輸出你認為最接近的 stage；若不確定，輸出 `未知`。
```

### 功能子頁專用提示詞

```text
請判斷這張畫面是不是功能子頁或活動子頁。

常見線索：
- 畫面中有大量按鈕與功能入口
- OCR 可能出現「航海任務 / 雲端戰鬥 / 菇菇武道會 / 競技場挑戰 / 挖礦 / 家族」等名稱
- 不像一般主頁面，但也不一定是戰鬥頁

請優先回傳最具體的 stage，不要硬塞成主頁面。
輸出 JSON，欄位同通用提示詞。
```

### 低信心整理提示詞

```text
以下是多張截圖的判讀結果。

請你幫我整理成「哪些畫面容易被誤判為未知」的清單，並分成：
1. 畫面類型
2. 典型特徵
3. 可能誤判原因
4. 建議標籤名稱

若同一類畫面出現多次，請合併成一類，不要逐張重複描述。
最後請輸出一份簡短表格。
```

## 實務建議

- 先把這份 prompt 固定成本地模型的標準輸入。
- 每次只要 `detector.py` 回 `未知`，就把截圖與 OCR 丟給本地模型補判。
- 如果後續要整理訓練資料，可以直接用模型輸出的 `stage` 當初步標籤，再人工抽查。
