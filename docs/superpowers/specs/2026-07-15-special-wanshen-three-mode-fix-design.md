# 萬神專用帳號三模式與精簡卡片修正設計

## 目標

修正寶兒（`web-001`）與暴哥（`web-002`）的專用卡片與執行模式。兩個帳號固定保留「完整腳本」、「網頁掛機」、「萬神專屬」三個入口；完整腳本與萬神專屬互斥，未啟用時不顯示任何執行資訊。

## 三種權威模式

模式不新增設定欄位，直接由既有兩個布林值推導：

| 模式 | `enabled` | `special_wanshen_enabled` | 執行行為 |
|---|---:|---:|---|
| `off` | `false` | `false` | 不執行自動腳本 |
| `full` | `true` | `false` | 執行原本完整自動化流程，遵守各任務既有設定 |
| `wanshen` | `true` | `true` | 只執行萬神專用流程，跳過一般與 WS 腳本 |

所有模式切換由單一後端請求一次寫入兩個值，避免前端連續送出兩次請求造成短暫的錯誤模式。非法模式回傳 HTTP 400；非萬神專用帳號回傳 HTTP 403。

## 執行路由

`special_wanshen_account` 只代表帳號具備專用模式能力，不再代表永遠攔截一般流程。

- 只有 `special_wanshen_account=true` 且 `special_wanshen_enabled=true` 時，`daily_pipeline` 才改走萬神專用流程。
- 只有上述兩個條件同時成立時，WS-first 階段才略過。
- `full` 模式會恢復既有完整 pipeline 與 WS 行為。
- `off` 模式由既有裝置總開關阻止自動執行。

## 儀表板

萬神專用帳號的操作列固定只有三個按鈕：

1. `啟用完整腳本`；完整模式中顯示 `完整腳本・已啟用`。
2. `開啟網頁掛機(不跑任何腳本，僅刷小怪用)`；網頁已開啟時顯示關閉按鈕。
3. `跑萬神試煉・未啟用`；萬神模式中顯示 `跑萬神試煉・已啟用`；本週完成時顯示完成狀態。

顯示規則：

- `off`：保留卡片標題、連線狀態、設定按鈕與三個模式按鈕；隱藏喚醒倒數、目前任務、目前步驟、更新時間、後端、任務徽章及日誌。
- `full`：顯示一般卡片執行資訊與一般任務進度。
- `wanshen`：顯示執行資訊，但任務進度只顯示萬神試煉。

手動網頁掛機不改變模式，仍送出 `manual_hold_until_closed=false`。

## API 與狀態

新增專用模式切換 API，接收 `off`、`full`、`wanshen`。`/api/status` 為專用帳號提供推導後的 `special_wanshen_mode`，前端不自行猜測互斥狀態。

既有 `/api/special_wanshen/<ip>` 保留相容性，但儀表板改用模式 API；舊的布林 POST 仍須維持可用。

## 測試

- API：三個模式各自原子寫入正確的兩個設定值，拒絕非法模式與一般帳號。
- Runtime：`full` 不攔截一般 pipeline/WS；`wanshen` 才攔截。
- Dashboard：固定存在三個按鈕、互斥標籤與模式 API；`off` 套用精簡卡片 class；三種進度顯示分支正確。
- 回歸：原有萬神排程、每日最多一次、週二至週六 03:00–06:59 規則不變。
