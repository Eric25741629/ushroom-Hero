## 1. 核心結論

- 賽季地圖用**整數格座標 `{gridX, gridY}`** 定址,**不是** cocos world 座標(-29999… 那套)。
- **出兵指令 `0x3906` 只帶 `{action, {gridX,gridY}, 小參數}`** — 沒有客戶端算的行軍路徑、**也沒有
  arena 那種 client battle seed**。距離 / 戰力 / 到達時間 / 勝負全由 server 解算。
  → **純 WS 可行**,不踩「客戶端驗證」紅線(與 arena `arena_combat` 的 trust boundary 不同)。
- `0x3903 {gridX,gridY}` 可純 WS 掃描格子內容(回傳每格佔用物 uid/類型/等級)→ 不需 cocos、不需 OCR
  就能找資源 / 遺跡。

## 4b. Module 24 (0x18) — 賽季任務領取 ✅ 已驗證純 WS

live 抓包(小寶 2026-06-24 03:03,領「本方佔領1塊資源Lv2」一項)。**領取是乾淨的純 WS,server 權威發獎。**

| cmd | dir | body | 說明 |
|-----|-----|------|------|
| `0x180e` (6158) | c2s | `{1: categoryId}` | **取任務清單**(本輪 categoryId=109) |
| `0x180e` (6158) | s2c | `{1: categoryId, 2: repeated{1:taskId, 2:groupId, 3:state, 4:claimFlag}}` | 每項任務狀態 |
| `0x180f` (6159) | c2s | `{1: categoryId, 2: taskId, 3: groupId}` | **領取**(本輪 `{109, 41515, 41503}`) |
| `0x180f` (6159) | s2c | `{1:categoryId, 2:taskId, 3:groupId, 4: repeated{1:itemId, 2:amount}}` | 領取結果(獎勵清單) |
| `0x0402` (1026) | s2c | `{1: reasonId, 2: repeated{1:itemId, 2:itemUid, 3:newAmount, ...}}` | 入庫 push(side-effect) |
| `0x0406` (1030) | s2c | `{1: reasonId, 2: repeated{1:itemId, 2:amount}}` | 獎勵彙總 push(side-effect) |

- `claimFlag`(s2c field4):**1 = 可領、2 = 已領、0 = 未完成/不可領**。
  本輪清單:41515 `{3:1,4:1}`=可領 → 領完變 `{4:2}`;41512 `{4:2}`=已領;41511/13/14 `{0,0}`=未完成。
- 領 41515 回的獎勵 `{270005:12000, 270006:12000, 270007:12000, 270020:10, 270026:2}`,與遊戲畫面
  「12000×3 + 10 + 物品」**完全吻合** → 確認 270005/6/7=木材/鐵/材料,270020/270026=瓶/物品。

**落地(純 WS 任務領取):**
```
send 0x180e {1:109}                       # 取賽季任務清單
for t in tasks where t.claimFlag == 1:    # 1=可領
    send 0x180f {1:109, 2:t.taskId, 3:t.groupId}   # 逐項領取,reply 帶獎勵
```
categoryId 109 = 賽季任務頁。其他頁(目標/懸賞)可能是別的 category,開該頁抓 `0x180e` 的 id 即可。

## 4d. 家的位置 / 四角落判定(重要)

> **cocos world 座標分不出角落。** 每個帳號「自己的家」都 render 在**同一個 scene-local world 座標**
> `(-28088, -1867)`,目標群也都在 world 的左上 —— 兩個帳號在 cocos 裡長得一模一樣。
> **能分辨在哪個角落的,只有 server 的絕對格座標(grid)。**

家格座標取得法(可靠度排序):
1. **行軍記錄 `0x3905` 的 from-grid**(精確,但需先出一次兵 → 受 `深夜無法行動` 限制,得白天)。
2. **locate 後的 `0x3903` 視野掃描格**(粗略,約家 ±2 格;免出兵,深夜也能讀)。
3. 點自家 base 格 → **不送 WS、無選單**(自家無動作),取不到。

已測(2026-06-24 凌晨):

| 帳號 | 裝置/CDP | player | 家 grid | 來源 |
|------|---------|--------|---------|------|
| 小寶 | 9226 | 89562953025122 | **(30,22)** 精確 | 0x3905 from-grid;locate-scan≈(28,23) |
| 閃電 | 9230(=5554) | 89555436834913 | **≈(31,27)** 待坐實 | locate-scan=(29,28),套小寶偏移推估;精確值待出兵 |

兩家 grid-Y 差很多(22 vs 28)→ 確認位置不同。**閃電精確家格座標待 10am 第一次駐守/進攻的行軍記錄。**

> **每週一第一次開賽季的 SOP(務必先做)**:賽季每週重置,家可能換角落。**開圖先確認自己家在四角的哪一角**
> —— 出一次兵讀 `0x3905` from-grid(精確),或 locate 後讀 `0x3903` 掃描格(粗略)。先確認家原點,再決定
> 駐守/進攻往哪個方向,否則重蹈 `SEA_DAILY §1`「方向固定滑錯邊」。
