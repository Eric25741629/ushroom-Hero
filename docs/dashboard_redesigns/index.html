菇勇者控制台 — 7 套儀表板改版方案

這是同一份 dashboard 的 7 種完整視覺方向，每一套都是可獨立開啟的 standalone HTML，內含 8 台假裝置（涵蓋 ONLINE / PAUSED / OFFLINE / DEGRADED / DISABLED 各種狀態）、所有 modal、倒數計時、泊車展開、每日進度與 live-view 等真實結構，並保留了原儀表板的所有 element ID、status class 與按鈕 pending lock 語意。

下方每個方案都附 一行摘要、signature moves、配色與字體說明，加上「開啟此方案」連結與一個內嵌縮放預覽。看完後直接回覆 「用 N 號」 即可，我會把那一套實作成正式的 templates/dashboard.html。

怎麼挑

  • 氛圍偏好：要深色科技感（1/7 號）、極簡紙感（2 號）、還是溫暖明亮（5/8 號）。
  • 資訊密度：座艙/終端機資訊最密；Swiss/編輯風最克制好讀。
  • 個性強度：粗獷主義最張揚；柔光 / Swiss 最低調耐看。
  • 長時間盯著看：建議優先試淺色柔光、Swiss、Bento 三套。

選定之後

我會把選定方案落地成正式 templates/dashboard.html，保留全部 JS / data hook（element ID、status class、polling 節奏、optimistic button-lock），只換視覺層，不動後端與輪詢邏輯。

深色玻璃座艙 (Dark Glass Cockpit)

dark-glass-cockpit.html
↗ 開啟此方案

真正分層玻璃擬態（不是平面深色模式）：深藍紫漸層底打上青/洋紅/紫的徑向光池、SVG 雜訊顆粒與緩慢飄移的掃描光帶。每一層面板都是半透明玻璃（backdrop-blur+saturate）配內高光/外陰影雙重陰影與髮絲邊框，深度靠堆疊與模糊呈現。8 台裝置各帶會發光脈動的狀態環、依狀態著色的頂部 accent rail、雙列任務讀數與琥珀色倒數 chip、2x2 遙測格、可展開泊車進度條與 monospace 日誌框。完整按鈕互動狀態系統（hover 上浮+光掃、focus neon ring、active 按壓、disabled、pending spinner）。Playwright 1440/390 驗過、零 JS error。

Palette

深淵藍黑底 #060810 / #0a0e1f / #11162e 上打徑向光池。Neon 語意色：青 #34e7ff（主色/ADB）、洋紅 #ff4fd8（H5/警示）、紫 #8b7bff（泊車/WS）、萊姆 #5cf2a0（ONLINE）、琥珀 #ffb338（PAUSED/倒數）、紅 #ff5d6c（危險）。

Typography

三聲部：Display = Sora（漸層標題、裝置名、大遙測數字）；Body = Noto Sans TC（繁中 UI）；Mono = Space Mono（所有遙測：IP、日誌、倒數、狀態碼），強化儀表讀數感、把機器資料與人類標籤分開。

Signature Moves

  • 真正分層玻璃擬態：多徑向漸層底 + backdrop-blur/saturate + 內高光/外陰影 + 髮絲邊 + SVG 顆粒 + 飄移掃描光帶。
  • 發光脈動狀態環：裝置肖像帶依狀態著色的環，ONLINE/DEGRADED 會 compositor-only 脈動，配狀態 accent rail 與心跳脈點。
  • 完整按鈕狀態系統：青/洋紅/琥珀/萊姆/危險/ghost/漸層 tonal 變體，各含 hover 光掃、上浮、focus neon ring、active 縮放、pending spinner。
  • 破格編輯式排版：非對稱頂部列（漸層標題 + mono OCR 狀態條 / 程式資訊卡 + 分段控制群），4-up 遙測條含 SVG sparkline。
  • 資料視覺化即系統：sparkline、青→洋紅泊車進度條、寶石品質直方圖、會動的挖礦 live-view canvas。

Swiss / International

swiss-grid.html
↗ 開啟此方案

嚴格的國際主義排版控制面：可見的模組化網格，每張裝置卡都與鄰卡共用同一條 1px ink 髮絲線（零間距），主導性的窄體 grotesque 報頭（其中一個詞用朱紅），數字被當成主要設計材料——超大 tabular-mono 倒數、每段/每台的索引號（00-08）、比例排版（05/08、04/06）。近單色米白紙 #F2F0E9 + 近黑 ink #15140E，只有唯一 accent 國際朱紅 #E63916（幾乎只用在主要動作與 live pulse）。狀態靠卡片左緣 2px 垂直「脊」髮絲線表達而非色塊，配色維持紀律。14 個 spec 區塊全數到位，零圓角、零陰影、淡 SVG 紙顆粒。

Palette

紙 #F2F0E9 / #EAE7DD / #FBFAF6；ink #15140E 配多階灰；髮絲線 #15140E + 柔線 #C9C5B6；唯一 accent 朱紅 #E63916。狀態近單色：PAUSED 赭 #B07A0C、OFFLINE 灰 #9C9A8B、DEGRADED 暗青 #1E6E63。

Typography

四角色 Swiss：Archivo（800/900）大標題與裝置名；Archivo Narrow（600/700）小型大寫 tracked 標籤與按鈕；Space Mono 所有數字（倒數/IP/比例/索引/日誌）做 tabular 對齊；Noto Sans TC 作 CJK 夥伴。

Signature Moves

  • 零間距模組化網格：裝置卡共用單條 1px ink 髮絲線，整支機隊讀成一張有刻度的帳本，網格是可見而非隱含的。
  • 數字當主角：超大 Space-Mono tabular 倒數（分/秒單位字縮小）、區塊與卡片索引號 00-08、比例排版、報頭旁巨大低對比 ghost「00」。
  • 單 accent 紀律 + 狀態脊：朱紅幾乎只出現在主 CTA 與 live pulse；裝置狀態用左緣 2px 垂直色脊 + 髮絲邊 tracked tag，配色永不氾濫。
  • 編輯式非對稱報頭：clamp 76px 窄體標題、髮絲 tick kicker 列、mono 日期，配右對齊 OCR 狀態堆疊。
  • 單一按鈕語言的完整互動狀態：髮絲分隔按鈕 hover 反轉成實心 ink、主按鈕 accent 填色、async 進入真實 pending（pulse + 旋轉 mono spinner）。

新粗獷主義中控台 (Neo-Brutalist Control Deck)

neo-brutalist.html
↗ 開啟此方案

徹底的 neo-brutalist 改版：每個表面都用 4-6px 純黑 ink 邊框、零模糊硬偏移投影、高飽和原色平塗塊，鋪在暖色點點報紙紙理上，Archivo Black 大寫 display + Space Mono 標籤。7 台裝置涵蓋全部五種狀態，旋轉貼紙狀態標、backend chip（adb/+ws/h5/真機/v5）、可展開泊車列含迷你進度條、終端綠日誌框、貼紙式每日進度徽章。每顆按鈕 :active 會實體下壓（位移 + 陰影歸零），含斜紋 disabled 與脈動 spinner pending。所有區塊、Labeler/Readme/倉庫頁與 6 個 modal 全保留；headless 驗過 HTTP 200、響應式 1440/1024/768/390 + reduced-motion fallback。

Palette

Ink #0d0d0d 鋪報紙紙 #f4ecd8 / #ece1c4 與純白塊。高飽和：黃 #ffd400、粉 #ff5da2、青 #1fd6c9(DEGRADED)、萊姆 #b4ff39(ONLINE)、橘 #ff6b35(PAUSED)、藍 #2d6cff、紅 #ff2e2e、紫 #9b6bff(H5)。OFFLINE 去飽和 #b8b0a0、DISABLED 斜紋 #cfc6b2。

Typography

Archivo Black（厚重 grotesk 大寫）所有 display 標題與大數字，報頭帶白色 text-shadow；Space Mono（700/400）所有標籤/按鈕/chip/日誌/表格/表單，強化原始機器感；Noto Sans TC 700 撐繁中內文。

Signature Moves

  • 會實體下壓的按鈕：每顆 .btn 靠 4px 硬偏移陰影，:active 位移 +4/+4px 同時陰影歸零，配斜紋 disabled 與雙 keyframe pending spinner。
  • 滿版旋轉貼紙標：狀態徽章 3deg 傾斜浮在卡片上方各帶 ink 邊與偏移陰影；每日進度徽章交替 ±1deg，整頁讀起來像手工貼上。
  • 暖報紙原始結構構圖：固定徑向點紙理、ink 側欄黃底線、飽和黃報頭白陰影標題、非對稱 5 塊摘要條（各不同平塗色，一塊內含 ink 迷你長條圖）。
  • 可見內部結構：裝置資訊是真實 2 欄 ink 分隔格，日誌是黑終端貼紙配萊姆 mono 與「› 」提示符，泊車列展開顯示每掛載剩餘時間條。
  • 氛圍 + 目的性動態維持 compositor-friendly：斜紋 modal scrim、頁面/modal 只用 transform/opacity、live-view 只在開啟時跑動畫挖礦 canvas，全部 gated 在 prefers-reduced-motion。

復古終端機 (Retro-Futuristic CRT Control Terminal)

retro-terminal.html
↗ 開啟此方案

賽博龐克 CRT 作戰室終端機。一切都是 monospace 磷光鋪在近黑上，框成命令列：標題是 root@ops_ 提示符配閃爍游標，每顆按鈕帶 sigil（$ || ▶ ⟳）與指令式標籤，modal 是終端視窗含紅綠燈點與 cfg@<ip> :: edit 提示，區段標題是 ASCII 橫線分隔（// DEVICE_MATRIX）。裝置卡成「unit」配脈動 LED 狀態點（ONLINE 擴張環、PAUSED 閃爍）、2 欄讀數格、可展開泊車列含水平時間條、[x]/[ ] 每日進度、彩色 INFO/WARN/ERR 日誌。數值用 VT323 CRT 字大尺寸呈現。層疊 CRT 氛圍：掃描線、動態顆粒、滾動掃描光暈、暈影管面曲率。

Palette

近黑底 #04070a / #0a1014 疊淡徑向綠/青暈。三磷光語意色：綠 #39ffb0（主/ONLINE）、琥珀 #ffb454（警/PAUSED）、青 #5ad9ff（資訊/DEGRADED/泊車）。洋紅 #ff5db1（破壞/警示）、紫 #b58bff（build/planner）、紅 #ff5a52（錯誤）。內文去飽和薄荷 #cfeede。

Typography

雙 monospace：JetBrains Mono（400-800 + 斜體）所有 UI/標籤/內文，乾淨終端個性、寬權重；VT323（真 bitmap CRT 字）只用在大數值讀出（倒數/ms/機隊統計/寶石品質/等級），數字像七段顯示般發光，與內文 mono 強尺度對比。

Signature Moves

  • 命令列框架即核心設計語言：提示符標題配閃爍游標、每顆按鈕前綴終端 sigil、modal 渲染成終端視窗（紅綠燈 + 提示符）、ASCII 重複虛線作區段分隔。
  • 從頭打造的層疊 CRT 氛圍：multiply 掃描線、SVG 顆粒用 steps() 動畫、緩慢 translateY 滾動掃描光暈、暈影 + 內陰影偽造管面曲率，全 compositor-friendly 且 reduced-motion 停用。
  • 狀態即實體 LED 硬體：每 unit 發光 LED 點，ONLINE 發擴張脈動環、PAUSED 用 steps() 硬閃；OFFLINE/DISABLED 去飽和變暗像死頻道，accent 色由單一 --accent CSS var 驅動。
  • 雙字族排版層次：VT323 bitmap 數字 18-34px 所有 live 資料對 JetBrains Mono 內文，尺度對比 + 真七段讀出感。
  • 資料視覺化融入系統：摘要區機隊 sparkline 條、可展開泊車列水平剩餘時間條、倉庫 CRT 數字 chip 寶石品質直方圖。

通透、高級消費級的「Soft Ops」控制面，是深色座艙的刻意對立面。暖去飽和紙底配多層粉彩漸層氛圍（右上蜜桃、左上藍、底玫瑰）與淡 multiply 顆粒，讓平面也有質地。每個凸起表面用一致的雙光源 neumorphic 陰影（左上高光、右下柔棕影）與超大圓角（最高 30px）。版面重組成：可收合左側狀態欄（74/230px）、編輯式 sticky 頂欄含超大 Fraunces serif 標題、非對稱機隊總覽條（健康條 + 甜甜圈 + sparkline 式資料視覺化）、便當但不均一的裝置網格（第一張卡用 1.3fr 跨更寬）、守護靈/神器附魔的倉庫入口橫幅。8 台裝置涵蓋全狀態，6 個 modal 用 inset soft-UI 表單。1440px 與 375px 都 live-verified。

Palette

暖紙畫布 #f4f0ea / #efe9e1 / #fbf8f3 / inset #e9e2d8；ink #33302b / #6f685d / #a39b8d 配 #e3dccf 髮絲。六組柔寶石語意對：鼠尾草 #7d9b76(online)、琥珀 #cf9a52(paused/accent)、玫瑰 #c97f7f(警示)、石板 #7e8aa3(web/adb)、青 #5fa3a0(degraded)、淡紫 #9487b5(ws)。招牌漸層 #f0c378→#e29b6f→#cf85a0。

Typography

Fraunces（光學尺寸 serif，360-800 含真斜體）所有 display：品牌/頁標題/裝置名/區段頭/modal 標題/大數字，給「light luxury」編輯個性；Manrope（人文幾何 sans，400-800）內文/標籤/按鈕/導覽；Spline Sans Mono 所有機器資料（IP/倒數/ms/日誌）。serif/sans/mono 三元建立尺度對比層次。

Signature Moves

  • 一致雙光源 neumorphic 陰影系統（--sh-up / --sh-in / --sh-float）套在每個表面，深度是真設計語言；pressed/inset 狀態真的看起來凹陷、卡片浮起，含設計過的 .btn:active 翻成 inset。
  • 機隊總覽條把資料視覺化當系統：分段 soft-inset 健康條配語意圖例、SVG 漸層甜甜圈表 OCR 成功率、進度條，取代通用 KPI 數字卡列。
  • 編輯式排版構圖：超大 Fraunces 標題含斜體玫瑰「em」字與大寫 tracked eyebrow、非對稱第一張裝置卡（1.3fr）、左狀態欄呼吸點，破格而非均一。
  • 每裝置狀態同時多層線索：左上色相徑向弧光暈、左緣狀態珠、呼吸語意 pill、offline/disabled 去飽和，全由單一 status class 驅動。
  • 滿版互動狀態：漸層主按鈕 hover 光掃、gear icon hover 轉 60deg、ghost 按鈕上浮加柔影、.btn-pending spinner 隱字保留 lock 語意、可存取自訂 soft toggle :active 加寬。
