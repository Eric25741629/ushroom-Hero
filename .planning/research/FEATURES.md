# FEATURES 研究（菇勇者自動掛機）

## Table Stakes（v1 應具備）

### 穩定執行
- 長時間循環掛機（可持續數小時以上）。
- 自動偵測卡死並自救（重試、回主畫面、重啟子流程）。
- 每台實例獨立容錯，單台失敗不拖垮全域。

### 即時控制（網頁分頁）
- 全域啟停。
- 單裝置啟停。
- 即時切換策略。
- 強制執行指定任務（未來含打車）。
- 查看每台模擬器/手機狀態（當前 state、最後心跳、錯誤碼）。

### 狀態機能力
- 狀態可視化（Idle/Running/Recovering/Paused/Error）。
- 每次狀態轉換有原因（trigger）與時間戳。
- 逾時與異常有預設轉移路徑。

## Differentiators（v1.5+）
- 策略收益評分與自動切策略。
- 跨裝置負載平衡（依設備性能/連線品質分配任務）。
- 行為回放與故障時間軸分析。

## Anti-features（先不做）
- 一開始就全自動 AI 決策策略生成。
- 公開多人 SaaS 與帳號系統。
- 完整分散式微服務重構。

## 依賴關係
- 即時控制分頁依賴：控制 API + 裝置狀態快照。
- 策略切換依賴：狀態機 guard + 排程器優先級機制。
- 長時穩定依賴：觀測指標 + 自動恢復策略。

## 複雜度評估
- 穩定性機制：高（涉及多模組行為與回歸風險）。
- 控制分頁：中（前後端接口明確即可迭代）。
- 策略擴充框架：中高（需標準化策略介面）。
